# 클라우드로 바꾼 뒤 화면이 비어 보일 때

## 결론부터

**데이터는 안 없어졌습니다.** 브라우저 안에 그대로 있고, 클라우드 화면이 그걸 안 볼 뿐입니다.

> ⚠️ 복구 전까지 **절대 하지 마세요**
> - 방문기록·캐시·사이트 데이터 삭제
> - 시크릿(비공개) 창으로 접속
> - 다른 브라우저나 다른 PC에서 복구 시도
>
> 데이터는 **입력하실 때 쓰던 그 브라우저**에만 있습니다.

---

## 방법 1 — 버튼 한 번 (이걸 먼저 해보세요)

1. 데이터를 입력하셨던 **그 브라우저**로 https://ax-mvp-factory-os.vercel.app/ 접속
2. 로그인
3. **고객 운영** 화면 맨 위에 파란 띠가 보입니다
   > 이 브라우저에 예전에 입력한 고객 **N곳**이 남아 있습니다…
4. **`클라우드로 옮기기`** 클릭
5. 끝. 브라우저에 있던 원본도 그대로 남습니다.

---

## 방법 2 — 배너가 안 보일 때 (확실한 방법)

### 1) 파일로 꺼내기

1. 그 브라우저에서 https://ax-mvp-factory-os.vercel.app/ 접속
2. **F12** (또는 Mac은 `⌥⌘I`) → 위쪽 **Console** 탭 클릭
3. 아래를 **전부 복사**해서 붙여넣고 **Enter**

```js
(function(){
  var raw = localStorage.getItem('axmvp.v1.operations_clients');
  if (!raw) { alert('이 브라우저에 저장된 고객 데이터가 없습니다.'); return; }
  var list = JSON.parse(raw);
  var file = { format:'ax-client-ops', version:1, exportedAt:new Date().toISOString(), count:list.length, clients:list };
  var blob = new Blob([JSON.stringify(file,null,2)], {type:'application/json'});
  var url = URL.createObjectURL(blob);
  var a = document.createElement('a');
  a.href = url; a.download = 'client-ops-rescue.json';
  document.body.appendChild(a); a.click(); document.body.removeChild(a);
  setTimeout(function(){ URL.revokeObjectURL(url); }, 1000);
  console.log('고객 ' + list.length + '곳을 파일로 저장했습니다: ' + list.map(function(c){return c.companyName}).join(', '));
})()
```

4. `client-ops-rescue.json` 파일이 다운로드됩니다
5. 콘솔에 **업체 이름이 쭉 나오는지** 확인하세요 (몇 곳인지도 나옵니다)

> 처음 붙여넣을 때 크롬이 `allow pasting` 을 입력하라고 하면, 그대로 타이핑하고 Enter 친 뒤 다시 붙여넣으세요.

### 2) 파일 되살리기

1. 로그인한 상태에서 **고객 운영** 화면
2. 위쪽 **`백업 불러오기`** 클릭 → 방금 받은 `client-ops-rescue.json` 선택
3. 물어보면 **[확인] 합치기** 선택
4. 업체 목록이 그대로 올라옵니다

---

## 그래도 안 나오면

콘솔에서 아래를 실행해 무엇이 남아 있는지 확인하세요.

```js
Object.keys(localStorage).filter(function(k){ return k.indexOf('axmvp') === 0 })
```

- `axmvp.v1.operations_clients` 가 목록에 **있으면** → 위 방법 2를 다시 시도
- **없으면** → 그 브라우저에는 데이터가 없습니다. 입력하실 때 쓰던 다른 브라우저·기기에서 같은 방법을 시도하세요.

---

## 앞으로

클라우드에 올라간 뒤로는 이런 일이 없습니다. 다만 습관 삼아 가끔 **`백업 내려받기`** 로 파일을 받아두시면 더 안전합니다.
