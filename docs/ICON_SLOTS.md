# 아이콘 자리 목록 (D-283)

> 대표(2026-10-24): "아이콘이 필요하면 일단 그 자리엔 임시로 아이콘 둬 줘. 나중에 내가 새로 만든 거 줄게."

지금 메뉴 · 바로가기 · 화면 제목 · 휴대폰 아래 메뉴 · 모듈 전체에 보이는 기능 아이콘은 **모두 임시**(무료 기본 아이콘 모음)다.
새 아이콘이 오면 **`src/config/iconSlots.ts` 한 곳**만 바꾼다 — 화면 코드는 손대지 않는다.

전문 모듈 안 세부 기능 줄(세금 계산기 · 고용지원금 …)은 지금 목록에 없다 — 그 줄도 바꾸고 싶으면 같은 표에 한 줄 더하면 된다(자리 key = 메뉴 줄 key).

## 새 아이콘 규격 (드릴 때)

- **형식**: SVG 가 가장 좋다. PNG 도 된다(정사각형 · 투명 배경 · 96×96px 이상).
- **크기**: 24×24 칸을 기준으로 그린다. 화면에서는 16px(메뉴) ~ 28px(휴대폰 바로가기)로 줄어 보인다 — 16px 에서도 알아볼 만큼 단순하게.
- **색**: **한 색(검정)** 으로 주면 기능 색(고객 파랑 · AI 보라 · 특허 호박 …)과 '지금 화면' 흰색이 저절로 입혀진다 — 권장.
  여러 색 그림이면 그림 그대로 보인다(이때는 기능 색 · 흰색 바뀜이 아이콘에 안 먹는다).
- **여백**: 그림 둘레 1~2px 은 비워 둔다.
- **파일 이름**: 아무거나 괜찮다(번호나 이름이면 충분) — 받아서 맞춰 넣는다.

## 바꾸는 법 (개발)

1. 파일을 `src/assets/icons/` 에 넣는다.
2. `src/config/iconSlots.ts` 맨 위에서 import 하고, 그 자리 줄에 `custom: 주소` 를 적는다. 여러 색 그림이면 `tint: false`.
3. `npm run test:catalog` 의 'D-283 지금은 새 아이콘 없음' 검사를 '새 아이콘 n곳' 으로 고친다.
4. 화면을 찍어 본다(메뉴 · 휴대폰 아래 메뉴 · 바로가기 · 화면 제목) — 16px 에서 뭉개지지 않는지.

새 화면에 기능 아이콘이 필요하면: 임시 아이콘을 두고 이 표와 `iconSlots.ts` 에 한 줄을 더한다.
