# 화면 규칙 (Design System)

새 화면을 만들거나 고칠 때 이 문서의 규칙을 따른다.
목적은 "예쁘게"가 아니라 **매일 켜도 피곤하지 않게** 하는 것이다.

부품은 `src/components/ui/primitives.tsx`, 글자 크기는 `src/index.css` 에 있다.

---

## 1. 한 화면은 세 단계로만 말한다

| 단계 | 무엇 | 어떻게 |
|---|---|---|
| 1 | 지금 봐야 하는 것 | 화면 맨 위, `t-page` / `t-card`, 필요하면 왼쪽 강조선 |
| 2 | 현재 상태 | 요약 숫자·목록, `t-card` / `t-sub` |
| 3 | 상세·참고 | `Disclosure` 로 접어 둔다 |

3단계를 펼친 채로 두지 않는다. 처음 보이는 것이 적을수록 좋다.

## 2. 색

| 색 | 뜻 | 예 |
|---|---|---|
| 빨강 `danger` | 마감 지남 · 서류가 없어 막힘 · 되돌릴 수 없는 행동 | "2일 지남", "서류 3건" |
| 주황 `warning` | 임박 · 고객 회신 대기 | "내일까지", "고객 대기" |
| 초록 `success` | 완료 · 확인됨 | "완료" |
| 브랜드 `brand` | 선택됨 · 주요 행동 · 새로 온 것 | 기본 버튼, 선택된 탭 |
| 무채색 | 그 밖의 전부 | |

- **업무 종류·기록 종류·일정 종류는 색으로 구분하지 않는다.** 지름 8px 점(`Dot`)만 쓴다.
- 값이 0이면 색을 쓰지 않는다. 아무 일도 없는데 화면이 빨개지면 안 된다.
- 급한 카드도 배경을 칠하지 않는다. 왼쪽 3px 선(`Surface showEdge`)으로만 표시한다.
  **숫자 칸(`MetricTile`)·목록 카드·'지금 이것부터' 줄에도 똑같이 적용된다.** 옅은 바탕이라도
  네 칸 중 세 칸이 물들면 어느 것이 제일 급한지 오히려 안 보인다 — 급한 순서는 정렬이 이미 말한다.
- 색만으로 상태를 전하지 않는다. 항상 글자 라벨을 함께 둔다.

## 3. 글자

`src/index.css` 의 여섯 단계만 쓴다. `text-[0.85rem]` 같은 임의 크기를 새로 만들지 않는다.

| 클래스 | 크기 | 쓰는 곳 |
|---|---|---|
| `t-page` | 25.6 / 28.8px | 화면 제목 (한 화면에 하나) |
| `t-section` | 19.2px | 구역 제목 |
| `t-card` | 16.8px | 카드에서 먼저 읽히는 줄 |
| `t-body` | 16px | 본문 |
| `t-sub` | 14.4px | 보조 설명 |
| `t-meta` | 13.1px | 배지·메타데이터 **전용** |
| `t-num` | 21.6 / 24.8px | 큰 숫자 |

- 굵게(`font-bold`)는 제목에만. 설명은 `font-medium` 이하.
- 글자 색은 세 단계 — `text-slate-900` 본문, `text-slate-600` 보조, `text-slate-400` 메타.

## 4. 여백과 크기

- 모바일 좌우 여백 16px, 카드 안 16~20px, 구역 사이 24px, 카드 사이 10~16px.
- 누르는 자리는 44px 이상 (`tap` 클래스 또는 `min-h-11`).
- 카드 안에 카드를 넣지 않는다. 목록은 `ListSurface` + `ListRow` (구분선만).

## 5. 버튼

- 한 카드·한 구역에 **강조 버튼(primary)은 하나**.
- `primary` 주요 행동 / `secondary` 보통 / `ghost` 부수 / `danger` 지우기·되돌릴 수 없는 것.
- 모바일에서 버튼이 셋을 넘으면 `BottomSheet` 로 옮긴다.

## 6. 배지

- 한 카드에 배지는 **두 개까지**.
- 항목이 여섯 개를 넘는 조각 묶음은 접는다. 기준은 **한 문장으로 말할 수 있어야 한다**:
  *손이 갈 일이 남았으면 보이고, 끝났거나 아직 시작 안 했으면 접힌다.*
  - 보인다 — 마감 지남 · 마감 임박 · 진행 중 · 고객 대기 · **보류**(사람이 멈춰 둔 것이라 이유를 봐야 한다)
  - 접힌다 — 완료 · 시작 전 · 해당 없음
- **접힘 단추는 무엇이 접혔는지 말한다.** `그 외 6` 이 아니라 `완료 3 · 시작 전 2`.
  개수만 쓰면 기준을 사용자가 추측해야 하고, 추측하게 만드는 순간 접기는 실패한다.
- 조각을 건드리면 그 카드는 펴 둔다 — 방금 누른 것이 접힘 속으로 사라지면 무엇이 바뀐 건지 알 수 없다.
- **값이 0이면 조각을 그리지 않는다.** '미수금 없음' · '서류 0/10' 은 아무 일도 없다는 뜻인데
  카드마다 두 칸을 차지한다.
- 종류·분류는 배지 대신 무채색 글자.
- 배지 색은 위 색 규칙을 따른다.

## 7. 모바일

- 하단 내비게이션 5칸(오늘·고객·이벤트·일정·더보기)은 고정이다. 늘리지 않는다.
- 상단은 `[메뉴] [화면 이름] [알림]` 세 개까지.
- 입력이 여러 칸이면 화면을 밀어내지 말고 `BottomSheet` 로 띄운다.
- 본문 맨 아래에는 `pb-safe-nav` 로 하단 내비 높이만큼 여백을 둔다.

## 8. 움직임

- 등장 620ms, 창 380ms, 색 전환 220ms. 반복 애니메이션은 쓰지 않는다.
- `ax-rise` 등장 / `ax-stagger` 차례로 / `ax-pop` 창 / `ax-lift` 손 올렸을 때.
- '화면 움직임 줄이기' 설정과 OS `prefers-reduced-motion` 에서 전부 멈춘다.

## 8-1. 색은 두 갈래로만 (D-25)

| 갈래 | 어디에 | 무엇을 말하나 |
|---|---|---|
| 어디인가 | 왼쪽 메뉴 아이콘 · 묶음 머리 칩(20~28px) | 지금 보는 곳이 어디인지 |
| 얼마나 급한가 | 카드 왼쪽 · 숫자칸 위쪽 3px 선, 숫자 글자색 | 마감 지남=빨강 · 7일 이내=주황 · 그 밖=무채색 |

- 업무 종류(특허·벤처인증 …)는 색으로 칠하지 않는다. 점 하나만.
- 급한 정도의 기준은 **경고 건수가 아니라 다음 할 일의 마감과 수금 연체**다.
  건수로 매기면 거의 모든 업체가 빨강이 되어 목록이 통째로 물든다.
- 목록의 정렬 순서와 색이 같은 방향을 보아야 한다 — 위에서부터 색이 옅어질 것.
- **바탕은 칠하지 않는다(D-57).** 옅게라도 칠하면 다섯 장 중 네 장이 물들어 제일 급한 하나가 사라진다.
  실측에서 큰 면에 칠해진 바탕이 19개였고, 걷어낸 뒤 4개(전부 '받을 돈 연체')만 남았다.

**클래스 이름을 이어 붙이지 말 것.** `` `text-nav-${accent}` `` 는 CSS 가 아예 생성되지 않는다(D-26).
이름을 통째로 적은 `Record` 에서 꺼낸다. 확인: `grep -o "\.text-nav-[a-z]*" dist/assets/*.css`

## 9. 한 줄 안에 글자와 버튼을 같이 두지 않는다 (짜부라짐 금지)

이것 하나로 "글자가 세로로 한 자씩 흐르는" 현상이 거의 다 생겼다.

```jsx
/* 하지 말 것 — 360px 에서 글자 칸이 20px 로 눌린다 */
<div className="flex flex-wrap items-center gap-3">
  <p className="min-w-0 flex-1">긴 안내 문구…</p>
  <div className="shrink-0"><Button>클라우드로 옮기기</Button></div>
</div>
```

`flex-1` 은 기준폭이 `0` 이라 브라우저가 "이미 다 들어갔다" 고 판단한다. 그래서
`flex-wrap` 이 있어도 줄이 넘어가지 않고, 글자 칸만 계속 좁아진다. 옆의 `shrink-0`
버튼은 한 뼘도 양보하지 않으므로 결국 글자가 세로로 흐른다.

```jsx
/* 이렇게 — 휴대폰에서는 줄을 나누고, 넓어지면 한 줄로 합친다 */
<div>
  <p className="break-keep">긴 안내 문구…</p>
  <div className="mt-3 flex flex-wrap gap-2"><Button>클라우드로 옮기기</Button></div>
</div>
```

규칙
- 한 줄짜리 flex 안에 **글자 + 고정폭 컨트롤(select · date · 버튼)** 을 같이 두려면
  좁은 폭에서 줄을 나눈다: 글자 쪽에 `w-full sm:w-auto sm:flex-1`.
- 데스크톱 한 줄 배치를 지키고 싶으면 감싼 칸에 `sm:contents` 를 주고 자식에 `order-*`
  를 달아 원래 순서를 되돌린다 (수금 줄이 이 방식이다).
- `<select>` 의 폭은 가장 긴 선택지가 정한다. 좁은 곳에 넣기 전에 그 폭을 생각한다.
- 화면 이름이 위쪽 띠와 같으면 큰 제목을 휴대폰에서 숨긴다(`ScreenTitle`·`PageHeader`
  가 자동으로 판단한다). 같은 말을 두 번 하지 않는다.

## 11. 간단 모드 (컨설팅 작업실)

`/studio/:id` 는 기본이 **간단 모드**다. 화면은 `CurrentTask` 하나만 그리고 단계·프롬프트 종류를 모른다.

- 강조 버튼(`variant="primary"`)은 **화면당 하나**. 위에 강조 블록이 이미 있으면 카드는 `quiet` 로 낮춘다.
- 간단 모드 본문은 `max-w-3xl`. 고급 보기(`?adv=1`)만 전폭을 쓴다(표·2단이 있으므로).
- 단계별 색을 만들지 않는다. brand + 무채색, 급할 때만 danger/warning/success.
- 개발자 낱말을 화면에 쓰지 않는다: `draft`·`superseded`·`GO/HOLD`·`Judge/Devil`·`Block`·`Skip`·`S0~S16`·`슬롯`·`잠금`.
  단위 시험이 실제 화면 문구를 25단계까지 훑으며 금지어를 찾고, E2E 가 간단 모드 화면을 확인한다.
  단계 이름은 `plainStageLabel` 로 한 번 걸러 쓴다 — 엔진 이름은 그대로 둔다.

## 11-2. 빈 칸을 늘어놓지 않는다

값이 없는 항목을 목록으로 펴 두면, 정작 적혀 있는 값이 그 사이에 묻힌다.

- 기본은 **적힌 것만** 보여 주고, 빈 칸은 아래 한 줄(`아직 안 적은 N칸 채우기`)로 접는다.
- 아무것도 안 적혀 있으면 접을 것이 없으므로 그때는 전부 편다.
- 접었다고 지운 것이 아니다 — 한 번 누르면 그대로 다 나온다.

## 11-2b. 목록 카드의 회사 정보는 두 무게로 나눈다

한 줄에 회색으로 다 붙이면 (`444-87-04089 · 1년차 · 최정철 · 경기 남양주시`) 아무것도 안 읽힌다.

- **진하게**(`slate-800 font-semibold`) — 대표자 · N년차 · 계약 단계. 전화를 걸거나 자격을 판단할 때 쓰는 값.
- **흐리게**(`slate-500`) — 지역 · 업종. 어느 회사인지 떠올리는 배경.
- **자체 줄 + `tabular-nums`** — 사업자등록번호. 읽는 값이 아니라 서류에 옮겨 적는 값이라,
  카드마다 같은 자리·같은 자릿수에 있어야 여러 장을 훑을 때 눈이 바로 찾는다.
- 메타 줄은 `t-meta`(13px)가 아니라 `t-sub`(14.4px). `t-meta` 는 배지 전용이다.
- **날것을 찍지 않는다.** 업력을 못 읽으면 설립일 원본(`20020216`)을 대신 보여 주지 말고 비운다.
  사업자번호는 `formatBusinessNumber` 를 거친다.

## 11-3. 범례가 필요하면 화면이 진 것이다

'빨강 = 마감 지남' 같은 색 설명을 화면에 적어 두지 않는다. 조각에 `7일 지남` 이라고
글자로 쓰여 있으면 색이 무슨 뜻인지 물어볼 일이 없다.

## 12. 마찰 제거 규칙 (처음 쓰는 50대 기준)

- **묻기 전에 순서를 지킨다**: 아는 값 → 서류에서 읽기 → 규칙 추천 → 문장 초안 → 보기 → [나중에] → 직접 입력.
- **모르면 넘어갈 수 있다**: 기획 단계의 질문에는 `deferrable` 을 붙인다. 제출에 가까운 단계(S7·S10·S13·S14)에는 붙이지 않는다.
- **시스템이 만든 문장에는 `koreanText` 를 쓴다**: 조사를 직접 이어 붙이지 말고, 가능하면 줄표(—)와 절로 나눈다.
- **전문용어에는 `glossary` 열쇠를 붙인다**: 화면에 설명을 늘어놓지 말고 [이게 뭔가요?] 로 접어 둔다.
- **`text-slate-400` 은 장식 아이콘에만**: 읽어야 하는 글자는 `slate-500` 이상. `t-meta`(13px)는 배지 전용.
- **준비된 정보가 0이면 그 목록을 감춘다**: 빈 목록은 화면만 밀어낸다.
