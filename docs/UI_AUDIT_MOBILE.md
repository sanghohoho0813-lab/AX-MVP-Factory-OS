# 모바일 UI 감사 · 2026-09-04

390px 아이폰 기준으로 실제 화면을 렌더링해 기록한 것이다.
"보기 나쁘다" 같은 인상이 아니라, 화면 길이·글자 크기·색 개수처럼 다시 재면
같은 값이 나오는 것만 적었다.

측정 방법은 `e2e/shots.mjs` (시드 데이터 `e2e/seed.mjs`, 업체 5곳·기록 6건·이벤트 3건).

---

## 1. 화면이 너무 길다

한 화면을 처음 열었을 때의 세로 길이 (390px 기준, 스크롤 포함 전체 높이):

| 화면 | 전 | 후 | 비고 |
|---|---:|---:|---|
| 오늘 | 6,352px | 2,961px | 휴대폰 화면 7.5장 → 3.5장 |
| 고객 운영 | 3,670px | 1,559px | |
| 업체 상세(개요) | 10,486px | 1,833px | 화면 12장 → 2장 |
| 업체 상세(업무) | 6,360px | 3,091px | |

업체 상세가 12장이나 됐던 가장 큰 이유는 버그였다. "업체 정보 수정 · 펼치기"
버튼이 상태만 바꾸고 실제로는 늘 펼쳐져 있었다 (입력칸 16개 + 메모).

## 2. 색이 서로 싸운다

한 화면에서 동시에 쓰인 색 계열:

- 업무 종류 6색 (cat-plan / doc / money / client / fund / neutral)
- 의미 3색 (danger / warning / success)
- 브랜드 1색
- 일정 종류 4색, 기록 종류 7색

고객 목록에서 업체 한 곳당 빨간 알약이 3개씩 붙었다 ("특허 · 서류 없음",
"벤처인증 · 서류 없음", "AX 개발 · 서류 없음"). 다섯 업체면 빨간 알약 12개.
전부 빨강이면 어느 것이 진짜 급한지 알 수 없다.

**바꾼 규칙**

| 색 | 쓰는 곳 | 안 쓰는 곳 |
|---|---|---|
| 빨강 | 마감 지남 · 서류가 없어 막힘 · 되돌릴 수 없는 행동 | 업무 종류, 강조 |
| 주황 | 마감 임박 · 고객 회신 대기 | |
| 초록 | 완료 · 확인됨 | |
| 브랜드(딥틸) | 선택된 것 · 주요 행동 버튼 | 정보 강조 |
| 무채색 | 그 밖의 전부 | |

업무 종류는 지름 8px 점 하나로만 구분한다.

## 3. 글자가 작고 위계가 없다

`text-[0.82rem]`(13.1px) 이하가 본문·설명·배지에 섞여 쓰였고, 같은 성격의 글이
화면마다 다른 크기였다.

**바꾼 기준** (`src/index.css`, rem 기준이라 글자 배율 설정이 그대로 적용된다)

| 이름 | 크기 | 쓰는 곳 |
|---|---|---|
| `t-page` | 25.6px (≥640px 28.8px) | 화면 제목, 한 화면에 하나 |
| `t-section` | 19.2px | 구역 제목 |
| `t-card` | 16.8px | 카드에서 가장 먼저 읽히는 줄 |
| `t-body` | 16px | 본문 |
| `t-sub` | 14.4px | 보조 설명 |
| `t-meta` | 13.1px | 배지·메타데이터 **전용** |
| `t-num` | 21.6px (≥480px 24.8px) | 큰 숫자 |

13px 아래는 쓰지 않는다.

## 4. 카드 안에 카드가 있다

업체 상세 개요 한 화면에 패널이 6겹까지 중첩됐다.
경고 목록 → 카드 → 알약 → 알약 안 아이콘.

**바꾼 것**: 카드 한 벌(`src/components/ui/primitives.tsx`)로 통일하고,
급한 카드도 배경을 칠하지 않는다. 왼쪽 3px 선 하나로 말한다.

## 5. 모바일이 작은 PC였다

- 상단에 햄버거·작업공간·가이드·알림·계정이 한 줄에서 경쟁했고, 작업공간
  이름은 "김팀장…" 으로 잘렸다.
- 화면을 옮기려면 반드시 서랍을 열어야 했다 (두 번 누름).
- 고객 운영 첫 화면 상단에 버튼 5개가 세 줄로 쌓였다.

**바꾼 것**

- 상단: `[메뉴] [지금 화면 이름] [알림]` 세 개.
- 하단 내비게이션: 오늘 · 고객 · 이벤트 · 일정 · 더보기 (한 번 누름).
- 자주 쓰지 않는 것(백업·일정·항목 관리·가이드·글자 크기)은 시트와 서랍으로.

## 6. 그 밖에 고친 것

- 헤더 검색 칸의 글자가 좁은 화면에서 칸 밖으로 나와 옆 버튼을 덮었다.
- 달력 칸의 업체명이 "한.." 으로 잘려 아무 정보도 주지 못했다 → 점으로 바꾸고
  내용은 그날 목록에서 읽는다.
- 금액 칸이 "3,500,00" 으로 잘렸다 → 요약 칸은 만원·억 단위로 줄여 적는다.
- 업무 일기가 종류 칩 7개부터 보여줬다 → 빈 칸 하나로 시작한다.

## 남은 것 (P2)

- AX 스튜디오 하위 화면(진단·설계·검증)은 화면 제목과 카드만 새 기준을 따르고,
  내부 표·단계 UI 는 그대로다. 매일 쓰는 화면이 아니라 이번 범위에서 뺐다.
- 업체 상세 '서류' 탭은 항목이 10개로 고정이라 접기 없이 그대로 둔다.
  항목이 더 늘면 접기가 필요하다.
- 데스크톱 1920 이상에서 본문 최대 폭(1840px)이 넓어 시선 이동이 길다.
