# 미래AI랩 OS — 1차 SaaS 상용화 로드맵 (2026-10-25)

대상: 중소기업 · 정책자금 컨설턴트. 1차 상품 = **일정·업무 · 고객사 · 서류 · 마케팅·브랜딩** 네 가지.
원칙: 새로 만들기보다 있는 것을 쓴다 · 대표 OS 를 건드리지 않는다 · 단계마다 실제 시험으로 확인하고 보고한다.

## 2. 부족한 것 (판매 전에 꼭)

1. **AI 가 대표 개인에게 맞춰져 있다** — 서버 지시문 첫 줄이 "미래AI랩 김상호 대표의 업무 비서", 마케팅 규칙 · 지식 묶음에
   김팀장 화자 · 끝인사 · 대표 경력 숫자(9년 · 100억+ · 사례 250건)가 박혀 있다. 고객이 쓰면 **남의 경력이 고객 콘텐츠에 들어간다**(지어낸 사실).
   그래서 마케팅은 지금 대표만 열린다.
2. **AI 비용 통제가 없다** — 사용량 제한이 서버 메모리에만 있어(서버가 나뉘거나 다시 켜지면 0) 고객별 월 한도 · 요금제별 한도를 지킬 수 없다.
3. **스스로 가입할 수 없다** — 가입하면 프로필만 생기고 작업공간 · 접근 등급은 대표가 SQL Editor 에서 줘야 한다.
4. **결제 · 구독 · 해지가 없다** — 요금제 계산은 화면에만 있고 가격 미정 · 결제 연동 없음 · 서버가 강제하지 않음.
5. **일부 자료가 브라우저에만** — 콘텐츠 묶음 AI 결과 · 영상 받아쓰기 · 스레드/숏폼 초안 · AI 기록 · 업체별 AI 상담 대화. 기기를 바꾸면 사라진다.
   서류 파일은 지워도 보관함에 남는다(비용). 전체 작업공간 내보내기가 없다.
6. **1차 상품 모양이 아니다** — 메뉴에 대표용 모듈이 섞여 있고, 첫 화면이 네 가지 업무 중심이 아니다. 카드뉴스가 노출된다.
