# 고도화 로드맵 — "초보자가 써도 바로 컨설팅 전문가" (2026-10-07 검토)

## 순서

1. **서류 자동 분류 정확도 (D-168 후보)** — 추가만
   - PDF 줄바꿈 살리기(pdf.js `hasEOL` · 줄 간격) → 제목 찾기 정상화. 파일 이름과 낱말 점수가 같은 서류를 가리키면 '확실' 로.
   - 폴더 끌어다 놓기(`webkitGetAsEntry`).
   - 두 서류가 같은 값을 말하면 자동 채움 · 사업자번호 검증 통과 OCR 은 사업자등록증 확실로.
   - 읽은 값 쓰기: 대표 생년월일 · 인증서 유효기간 → 서류 만료 · 재무제표 → 매출/영업이익 · 중소기업확인서 → 기업 규모.
2. **'검토함' 한 곳 (D-169 후보)** — 추가(새 화면). 흩어진 확인(정보 확인 · 기타 칸 · 겹친 서류 · 다시 분류 제안 · 자동으로 넣은 중요 값 최종 OK)을 한 줄 목록으로. 올리기 요약은 업체 기록에 남김.
   - 🚨 기존 확인 화면들을 없애는 것은 대표 확인 뒤에만.
3. **추천을 맨 위에 · 크게 (D-170 후보)** — 업체 상세 맨 위 '이 업체에 먼저 제안할 것 3가지'(가능성 · 한 줄 이유 · 열기) · 고객 관리 카드에 추천 띠(휴대폰에서도) · '추천 많은 순' 정렬.
4. **예상 금액 · 금액순 · 모자란 서류 → 요청 문구** — 판정에 금액/근거/마감 붙이기(엔진이 이미 계산하는 값 재사용) · 금액 · 마감 순 정렬 · 'X 받기' 를 카톡/고객 화면 요청으로.
   - 🚨 추천 순서 기준이 바뀐다(판정 등급 → 금액 · 마감). 대표 확인 뒤에.
5. **상황 예시 카탈로그 (한 번 누르면 설계)** — 절세 11 · 계산기 2(t7 · t8) · 고용 4 · 연구소 2 · 창업감면 3 · 정책자금 3 = 25개. 누르면 바로 계산 · 업체 숫자 채움 · '이 상황엔 이 숫자가 필요' ✓/✗ + 대표님께 보낼 요청 문구. `?preset=` 로 추천 카드에서 바로 열기.
6. **판정 넓히기** — 벤처/특허 · 연구개발 세액공제 · 통합고용세액공제 · 연구소는 연구소 도구 판정 그대로 · 절세는 급여/배당 대략 계산.
7. **상황별 한 장 설계서** — 예: '청년 2명 채용' = 고용지원금 합계 + 세액공제 + 정책자금 힌트 + 추천 행동 → 업체에 붙이기.
