## 3. 기술 구조(클라이언트 코드로 본 것)

- 서버가 그리는 페이지(nginx) + jQuery · Tailwind CDN. 채팅만 ES 모듈 34개. 같은 인라인 스크립트(13.5KB · 32KB)가 모든 페이지에 복사돼 있음.
- 채팅만 스트리밍(POST fetch 로 `data: {json}` 줄 읽기 · `start/status/text/done/error`) + socket.io 로 다른 탭에 같은 답 비춤. 나머지 생성기는 GET 한 번 + **시간으로 움직이는 가짜 진행 막대**(5단계 · "최대 5분").
- 쓰는 AI(클라이언트 코드에 적힌 이름): 채팅 Anthropic Claude(`claude-sonnet-4-5`), 릴스 분석 Google Gemini, 광고 그림 Freepik, 검색량 네이버.
- 30초마다 `/api/build-version` 을 보고 새 배포면 새로고침.
- 분석 · 상담: Meta 픽셀 · 네이버 애널리틱스 · 채널톡 · 카카오 채널.

## 4. 횟수(크레딧) 차감 흐름

1. 남은 횟수 읽기(`/api/user-subscription-info`) → "N회 쓰입니다" 확인 창
2. 확인 → **브라우저가** `POST /api/deduct-credit` 로 먼저 차감
3. 성공하면 생성 요청(GET)

서버가 따로 막는지는 못 봤다. 생성 전에 사업체 정보가 다 찼는지 확인하고, 아니면 온보딩으로 보냄.

## 5. 보관 모양

결과마다 `content_type` · 기능 종류 · 넣은 값 · 결과 HTML · 원래 요청 · `root_content_id`(수정본 → 원본 연결) ·
